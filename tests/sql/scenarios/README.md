# Test scenarios

Named, reusable multi-tenant scenarios (two organizations, staff role/branch
variants, guest session states, finalized bill, subscription states) belong here.

These are blocked until Agent 1's schema and Agent 2's RPC/token contracts are
available. Do not encode unapproved business rules, billing arithmetic, guest
token expiry duration, waitlist restriction behavior, or permission mappings.

See `docs/test-blockers.md`.
